<p>各平台入口不同，但填的参数是同一套：地址、端口、账号、密码、协议。本文先讲这五个参数从哪来，再按 Windows、macOS、安卓、iOS 分别给入口路径，然后讲浏览器与全局代理的差别，最后是验证排错和常见问答。</p>
<h2>一、先备齐五个参数</h2>
<p>地址、端口、用户名、密码、协议。协议多为 SOCKS5 或 HTTP，两者填法一样，能不能用取决于服务端开的是哪种，填错会直接连不上。</p>
<p>如果是白名单授权，就没有账号密码，改为在服务方后台登记你的出口地址。这种方式省事，但换网络就要重新登记，出差时容易忘。</p>

<h2>二、Windows 怎么配</h2>
<p>系统级入口在设置里的代理项，填地址和端口即可，账号密码在首次连接时弹窗输入。这种方式只对读系统代理的软件有效。</p>
<p>想要全局生效，用支持 TUN 模式的客户端，把流量整机接管。TUN 需要管理员权限，装完先确认虚拟网卡起来了，否则等于没开。</p>
<h3>改了不生效先查什么</h3>
<p>先看有没有点保存，再看是不是同时开了两个代理客户端。两个都开时流量走向不确定，表现是时通时不通。</p>
<h2>三、macOS 怎么配</h2>
<p>系统设置的网络里选当前连接，进代理选项卡，勾选对应协议后填地址端口。SOCKS5 与 HTTP 要分别勾，只勾一个另一个不生效。</p>
<p>填完点应用，再打开浏览器验证。改完不生效，多数是忘了点应用，或者客户端与服务端的协议对不上。</p>
<h2>四、手机怎么配</h2>
<p>安卓在 WLAN 列表长按当前网络，改高级选项里的代理，填主机名与端口。移动数据下没有这个入口，只能靠客户端软件。</p>
<p>iOS 在无线局域网里点当前网络右侧的详情，滑到底部配置代理，选手动后填服务器与端口。系统代理只对部分应用生效，配完还要关掉省电限制，否则客户端会被后台清掉。</p>
<h3>手机上的两个坑</h3>
<p>一是切换网络后代理解除，Wi-Fi 转移动数据就失效。二是部分应用不读系统代理，看着配好了实际没走，需要开隧道模式。</p>
<h2>五、浏览器单独配还是全局配</h2>
<p>只做网页操作，浏览器单独配最省事，配错了不影响其他软件。需要客户端软件一起走代理的，必须全局。</p>
<h3>独立配置文件怎么用</h3>
<p>浏览器单独配常见做法是装代理扩展，或在启动参数里指定。多账号场景用独立配置文件，每个配置文件一套出口，互不影响。</p>

<h2>六、验证与排错</h2>
<p>验证分三步：打开显示出口地址的页面，看是不是目标地址；访问查询站，看归属与 ASN；打开常用业务页，看能否正常加载。</p>
<p>第一步不过，问题在配置；第一步过、第三步不过，问题多在 DNS 或站点策略。按这两条分开查，比逐个试快得多。</p>
<h2>常见问答</h2>
<h3>为什么填了代理还是访问不了？</h3>
<p>答：先确认协议类型对不对，再看密码有没有特殊字符需要转义。都正常的话，检查服务端是否开了白名单限制。</p>
<h3>系统代理和客户端软件冲突吗？</h3>
<p>答：会。同时开两个，流量走向不确定。只留一个，另一个彻底退出，包括托盘里的后台进程。</p>
<h3>手机能用电脑的代理吗？</h3>
<p>答：同一局域网下可以，把手机代理指向电脑的内网地址与端口，电脑端允许局域网连接。跨网络不行。</p>
<h3>需要改 DNS 吗？</h3>
<p>答：走代理时应开启远程解析，让解析请求从出口侧发出。这一步能避免地址在国外、解析在本地的错配。</p>
